# دليل الاستخدام — للأدمن والمقدم

## أولًا: الأدمن (إدارة المحتوى)

**الدخول:** الصفحة الرئيسية ← «لوحة الأدمن». بعد 5 محاولات خاطئة يُقفل الدخول 5 دقائق.

**إضافة فئة:** «إضافة فئة» ← اكتب الاسم (2–40 حرفًا، لا يتكرر) ← اسحب صورة أو اضغط لاختيارها (JPG/PNG/WEBP) ← حدّد الجزء الظاهر في نافذة القص ← اختر لونًا.

**بنك الأسئلة:** لكل فئة ثلاثة مستويات (200 و400 و600 نقطة)، ويمكنك إضافة أي عدد من الأسئلة لكل مستوى (حتى 50). اضغط «+ إضافة سؤال» تحت المستوى ← اكتب السؤال والإجابة (والصور والملاحظات إن أردت) ← «إضافة السؤال». ترى على اليمين معاينة لشكل السؤال على الشاشة الكبيرة، ويمكنك نقل السؤال لمستوى آخر من أعلى النافذة. خانة البحث فوق القائمة تساعدك عندما يكبر البنك.
> الأسئلة تبقى مسودة حتى تضغط **«حفظ»** أسفل الصفحة. إذا حاولت المغادرة دون حفظ تظهر رسالة تحذير.

**كيف تُختار الأسئلة؟** في كل مباراة يُسحب سؤالان عشوائيًا من كل مستوى، مع تفضيل الأسئلة التي لم تظهر في المباريات الأخيرة. فكلما زادت أسئلة البنك قلّ التكرار مع نفس الجمهور.

**متى تظهر الفئة للعب؟** عندما تكون: ✅ مفعّلة + فيها صورة + سؤالان على الأقل من كل مستوى. البطاقة في لوحة التحكم تعرض «جاهزة ✅» أو ما ينقصها، مثل «ناقصة 400: ينقص 1 ⚠️».

**معاينة:** زر «معاينة» يعرض لوحة بعيّنة عشوائية كما ستظهر في مباراة (زر «سحب عيّنة أخرى» يغيّرها)، وتحتها كل أسئلة البنك. افتح أي سؤال لتراه على الشاشة الكبيرة دون احتساب نقاط.

**الحذف:** يحذف الفئة مع كل أسئلتها وصورها بعد تأكيد يوضح عدد الأسئلة المحذوفة.
> الفئة المستخدمة في مباراة جارية مقفلة 🔒 لا تُعدّل ولا تُحذف حتى تنتهي المباراة.

**الإعدادات:** مدة المؤقت (بدون/15/30/45/60 ثانية)، الأصوات، خصم النقاط عند الخطأ، فرصة السرقة، تغيير كلمة المرور، التصدير والاستيراد (دمج أو استبدال)، وحذف الفئات التجريبية أو إعادتها.

## ثانيًا: المقدم (إدارة المباراة)

**البدء:** «ابدأ اللعب» ← اختر فردي أو فريقان ← اكتب الأسماء واختر الألوان ← اختر من فئة إلى 3 فئات ← «ابدأ المباراة».

**أثناء اللعب:**
1. اضغط على بطاقة (200/400/600) ← يُفتح السؤال ويبدأ المؤقت.
2. اضغط **مسافة** أو «إظهار الإجابة».
3. اختر النتيجة:
   - **فردي:** `1` إجابة صحيحة، `2` إجابة خاطئة.
   - **فريقان:** زر الفريق صاحب الدور = إجابة صحيحة. زر الفريق الآخر = **سرقة** (أخطأ صاحب الدور فأجاب الآخر). `0` = لم يُجب أحد.
4. الدور ينتقل تلقائيًا بعد كل سؤال، والفريق صاحب الدور مُبرز في الأعلى.

**أدوات المقدم أسفل اللوحة:** تعديل النقاط يدويًا (مع سبب يُسجَّل، ويمكن تغيير صاحب الدور منه) • تراجع • ملء الشاشة • كتم الصوت • إنهاء المباراة.

**ملاحظة للمقدم:** إذا كتب الأدمن ملاحظة للسؤال يظهر زر «ملاحظة للمقدم» يفتحها ويغلقها. في التشغيل على جهاز واحد يراها الجمهور أيضًا، فافتحها فقط عند الحاجة.

**النهاية:** تظهر النتيجة تلقائيًا بعد آخر سؤال. عند التعادل يظهر زر «سؤال فاصل» (سؤال 600 من فئة لم تُلعب). بعدها اختر: مباراة جديدة بنفس اللاعبين، أو اختيار فئة أخرى، أو الصفحة الرئيسية.

**انقطاع أو تحديث للصفحة؟** لا يضيع شيء. عند فتح اللعبة مرة أخرى يظهر سؤال: «استكمال المباراة السابقة» أو «بدء مباراة جديدة».

### اختصارات لوحة المفاتيح (اضغط `?` لعرضها داخل اللعبة)

| المفتاح | الوظيفة |
|---|---|
| Space | إظهار الإجابة |
| 1 / 2 | الفريق الأول / الثاني — أو صح / خطأ في الفردي |
| 0 | لم يُجب أحد |
| P | إيقاف المؤقت / استئنافه |
| R | إعادة المؤقت |
| Esc | إغلاق السؤال دون احتساب (يعود متاحًا) |
| F | ملء الشاشة |
| M | كتم الصوت |
| Ctrl+Z | التراجع عن آخر احتساب أو تعديل (حتى 10 خطوات) |

تعمل الاختصارات مع لوحة المفاتيح العربية والإنجليزية.
