# سين جيم

لعبة مسابقات ثقافية عربية للفعاليات والمدارس والتجمعات العائلية. تعمل على جهاز واحد متصل بشاشة كبيرة أو بروجكتر، دون خادم ودون إنترنت.

**للتشغيل:** افتح `index.html` في Chrome أو Edge.
**دخول الأدمن أول مرة:** `admin` / `admin123` (غيّرها من الإعدادات).

- [دليل التشغيل](docs/دليل-التشغيل.md)
- [دليل الاستخدام للأدمن والمقدم](docs/دليل-الاستخدام.md)
- [التقرير الختامي](docs/التقرير-الختامي.md)
